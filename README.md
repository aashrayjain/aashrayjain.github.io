---

## 📱 Responsive Design

The layout adapts to desktop, tablet and mobile screens.

On smaller screens:

- Navigation collapses into a Bootstrap menu
- Hero content adapts to the viewport
- Statistics use a responsive grid
- Cards reduce internal spacing
- Certification cards switch to a single-column layout
- Section spacing is optimized for mobile

---

## 🖨️ Print / PDF Support

A dedicated print stylesheet provides a cleaner printable version of the portfolio.

During printing:

- Navigation controls are hidden
- Theme controls are hidden
- Social controls are hidden
- Background is converted to a print-friendly layout
- Card shadows are removed
- Sections receive print-friendly spacing
- Links are rendered in a printable format

The portfolio can therefore be saved as a PDF directly from the browser's print dialog.

## 🚀 Running Locally

No package installation or backend server is required.

### Clone the repository

```bash
git clone https://github.com/aashrayjain/aashrayjain.github.io.git
cd aashrayjain.github.io
```

### Open directly

Open `index.html` in a modern web browser.

### Or use a local server

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
